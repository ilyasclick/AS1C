# Internal GAS tools

This folder contains genericized copies of the AS1C GAS operational helpers.
Set AS1C_* environment variables with the authorized OS user, script IDs, OAuth file paths, Google account names, clasp command, and source workspaces.
These are code examples; do not run them against production before validating the requested operation, exact identity, baseline, backups and approval.
OAuth tokens and clasp auth files are not part of this repository.
